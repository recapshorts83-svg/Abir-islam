# Viral Video Pro — README

টেলিগ্রাম মিনি-অ্যাপের মতো দেখতে **ভিডিও টাস্ক + পয়েন্ট** ওয়েবসাইট, সাথে সম্পূর্ণ **অ্যাডমিন প্যানেল**।
PHP + MySQL দিয়ে বানানো — যেকোনো সাধারণ হোস্টিং (cPanel) এ চলবে, কোনো ফ্রেমওয়ার্ক বা composer লাগবে না।

> আপনার দেওয়া লিংকের মতো (`t.me/bot/Video?startapp=...`) অ্যাপটি টেলিগ্রামের ভেতরেও চালানো যাবে — নিচে "টেলিগ্রাম মিনি-অ্যাপ হিসেবে চালানো" অংশ দেখুন।

## ১. যা যা আছে

**ইউজার অ্যাপ (মোবাইল ফার্স্ট, বাংলা)**

| পেজ | কাজ |
|---|---|
| `index.php` | ব্যালেন্স কার্ড, ডেইলি চেক-ইন, আজকের টাস্ক, পরিসংখ্যান |
| `tasks.php` | সব টাস্ক — ফিল্টার (সব / এখনই করা যাবে / অপেক্ষামান) |
| `task.php` | ভিডিও প্লেয়ার + কাউন্টডাউন টাইমার + ক্লেইম বাটন |
| `leaderboard.php` | সর্বকালের ও শেষ ৭ দিনের র‍্যাংকিং |
| `profile.php` | প্রোফাইল, লেনদেনের হিস্ট্রি, পাসওয়ার্ড বদল, লগআউট |
| `register.php` / `login.php` | রেজিস্ট্রেশন ও লগইন |

**অ্যাডমিন প্যানেল** (`/admin/`)

- ড্যাশবোর্ড — ইউজার/ক্লেইম/পয়েন্টের পরিসংখ্যান, ৭ দিনের গ্রাফ, জনপ্রিয় টাস্ক
- ইউজার ম্যানেজমেন্ট — সার্চ, ব্লক/আনব্লক, রোল বদল, পয়েন্ট যোগ/কাটা, পাসওয়ার্ড রিসেট, ডিলিট
- টাস্ক ম্যানেজমেন্ট — নতুন টাস্ক, এডিট, পজ/চালু, ক্রম বদল, ডিলিট
- লেনদেন — সব পয়েন্ট মুভমেন্টের লগ + CSV এক্সপোর্ট
- সেটিংস — সাইটের নাম, পয়েন্টের নাম, চেক-ইন বোনাস, দৈনিক লিমিট, রেফারেল অন/অফ, নোটিশ, মেইনটেন্যান্স মোড

**যা ইচ্ছে করেই বন্ধ রাখা হয়েছে (আপনার নির্দেশ অনুযায়ী)**

- ❌ কোনো টাকা, ডিপোজিট বা উইথড্র নেই — শুধু পয়েন্ট
- ❌ রেফারেল সিস্টেম ডিফল্টে বন্ধ (`সেটিংস → রেফারেল` থেকে এক ক্লিকে চালু করা যায়)

## ২. ইনস্টল (cPanel / শেয়ার্ড হোস্টিং)

### ধাপ ১ — ডেটাবেস বানান
cPanel → **MySQL Databases** →
1. নতুন ডেটাবেস বানান (যেমন `viralvideo_pro`)
2. নতুন ইউজার বানান + পাসওয়ার্ড দিন
3. ইউজারকে ডেটাবেসে **All Privileges** দিন

### ধাপ ২ — `config.php` এডিট করুন
```php
'db' => [
    'driver' => 'mysql',
    'host'   => 'localhost',
    'port'   => 3306,
    'name'   => 'আপনার_ডেটাবেস_নাম',
    'user'   => 'আপনার_ডেটাবেস_ইউজার',
    'pass'   => 'আপনার_পাসওয়ার্ড',
],
```
> অনেক হোস্টিং-এ ডেটাবেস নাম/ইউজারের আগে অ্যাকাউন্ট প্রিফিক্স থাকে, যেমন `myacc_viralvideo`। পুরো নামটাই বসান।

### ধাপ ৩ — ফাইল আপলোড
পুরো ফোল্ডারের ফাইলগুলো `public_html` (বা সাবফোল্ডার) এ আপলোড করুন — File Manager বা FTP দিয়ে।

### ধাপ ৪ — ইনস্টলার চালান
ব্রাউজারে খুলুন: `https://yoursite.com/install.php`

- সাইটের নাম, অ্যাডমিন নাম, ইউজারনেম, পাসওয়ার্ড দিন
- "ডেমো টাস্ক যোগ করুন" টিক দেওয়া থাকলে ৫টি উদাহরণ টাস্ক তৈরি হবে
- **সাবমিট** → টেবিল, সেটিংস ও অ্যাডমিন অ্যাকাউন্ট তৈরি হয়ে যাবে

### ধাপ ৫ — ইনস্টলার ডিলিট করুন
`install.php` ফাইলটি সার্ভার থেকে **মুছে ফেলুন** (নিরাপত্তার জন্য জরুরি)।

### ধাপ ৬ — লগইন
- ইউজার/অ্যাডমিন লগইন: `https://yoursite.com/login.php`
- অ্যাডমিন প্যানেল: `https://yoursite.com/admin/`

## ৩. প্রথম দিনের সেটআপ চেকলিস্ট

1. **সেটিংস** → সাইটের নাম, পয়েন্টের নাম, সাপোর্ট লিংক (আপনার টেলিগ্রাম) দিন
2. **টাস্ক** → ডেমো টাস্কগুলো এডিট করে আপনার আসল ভিডিও লিংক বসান, অথবা ডিলিট করে নতুন বানান
3. প্রতিটি টাস্কে ঠিক করুন: রিওয়ার্ড, দেখার সময় (সেকেন্ড), কুলডাউন (ঘণ্টা), দৈনিক লিমিট
4. **সেটিংস → রিওয়ার্ড** → চেক-ইন পয়েন্ট ও দিনে সর্বোচ্চ টাস্ক ঠিক করুন
5. টেলিগ্রাম/হোয়াটসঅ্যাপে লিংক শেয়ার করে টেস্ট ইউজার দিয়ে পুরো ফ্লো একবার চালিয়ে দেখুন

## ৪. টেলিগ্রাম মিনি-অ্যাপ হিসেবে চালানো (ঐচ্ছিক)

আপনার দেওয়া লিংকটি ছিল এমন একটা অ্যাপের: `t.me/cashnesttask_bot/Video?startapp=ref_...`।
একইভাবে নিজের বটে এই সাইট বসাতে:

1. টেলিগ্রামে **@BotFather** → `/newbot` → বট বানান → টোকেন সংরক্ষণ করুন
2. সাইটটি অবশ্যই **HTTPS** এ হোস্ট করুন (টেলিগ্রামের শর্ত)
3. BotFather এ `/newapp` → বট বেছে নিন → অ্যাপের নাম, ছবি, **Web App URL** = `https://yoursite.com/index.php`
4. এখন `https://t.me/আপনার_বট/অ্যাপের_নাম` লিংক দিয়ে অ্যাপ খুলবে

**গুরুত্বপূর্ণ:** এই সাইটে লগইন হয় ইউজারনেম+পাসওয়ার্ড দিয়ে (ডেটা আপনার নিজের ডেটাবেসে থাকে)।
টেলিগ্রামের `initData` দিয়ে অটো-লগইন চাইলে সেটা আলাদা ইন্টিগ্রেশন — দরকার হলে বলুন, যোগ করে দেওয়া যাবে।

**রেফারেল লিংক** (সেটিংসে চালু করলে): `https://yoursite.com/register.php?ref=কোড`
আপনার লিংকের `?startapp=ref_123` স্টাইল চাইলে `startapp` প্যারামিটারও পড়া যায় — চাইলে যোগ করা যাবে।

## ৬. নিরাপত্তা — যা আগে থেকেই করা আছে

- সব SQL query **prepared statement** দিয়ে (SQL ইনজেকশন প্রতিরোধ)
- পাসওয়ার্ড `password_hash()` (bcrypt) দিয়ে সেভ
- প্রতিটি ফর্মে **CSRF টোকেন** যাচাই
- আউটপুটে `htmlspecialchars()` — XSS প্রতিরোধ
- লগইনে ব্রুট-ফোর্স লিমিট (৬ বার ভুল হলে ১০ মিনিট লক)
- সেশন ফিক্সেশন প্রতিরোধ (`session_regenerate_id`)
- ক্লেইমে অ্যান্টি-চিট: ভিডিও পেজ খোলার সময় সেশন-এ রেকর্ড হয়, নির্দিষ্ট সময় পার না হলে ক্লেইম হবে না; ডাবল-ক্লেইম ব্লক

**আপনার করণীয়**
- লাইভ সাইটে `config.php` এ `'debug' => false` রাখুন
- হোস্টিং-এ **HTTPS** চালু করুন
- অ্যাডমিন পাসওয়ার্ড শক্ত রাখুন, `install.php` ডিলিট করুন
- নিয়মিত ডেটাবেস ব্যাকআপ নিন (cPanel → Backup)

## ৭. কাস্টমাইজ

**রং বদলাতে** — `assets/css/style.css` এর উপরে:
```css
:root {
  --acc-1: #7c5cff;   /* প্রধান রং */
  --acc-2: #22d3ee;   /* দ্বিতীয় রং */
  --bg:    #070b16;   /* ব্যাকগ্রাউন্ড */
  --muted: #98a5c8;   /* হালকা লেখা */
}
```

**লোগো/নাম** — হেডারের বৃত্তাকার "V" বদলাতে `includes/header.php` ও `includes/footer.php`-এ `brand-dot` লেখাটা বদলান।

**ভিডিও** — ইউটিউব লিংক দিলে সাইটের ভেতরেই প্লে হবে (embed)। ফেসবুক/টিকটক/ওয়েবসাইট লিংক নতুন ট্যাবে খুলবে।
কাস্টম থাম্বনেইল না দিলে ইউটিউবের থাম্বনেইল অটো আসবে।

## ৯. সমস্যা হলে

| বাংলা অক্ষর ভাঙা দেখাচ্ছে | ডেটাবেস `utf8mb4` কিনা দেখুন (db.sql এমনিতেই utf8mb4) |

## ১০. পরবর্তী ধাপে যা যোগ করা যায়

- অ্যাডমিন নোটিফিকেশন (টেলিগ্রাম বটে মেসেজ)
- ইউজার লেভেল / ব্যাজ সিস্টেম
